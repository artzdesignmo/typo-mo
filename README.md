# Typo Mo — Kinetic Typography Studio

A kinetic typography playground that runs entirely in the browser. Type something — the letters react to your cursor with spring physics.

**Live demo:** https://artzdesignmo.github.io/typo-mo/

## Features

- **4 behaviours** — Pressure (letters swell near the cursor), Repel (letters flee), Gravity (letters fall and bounce), Wave (letters surf a sine wave)
- **Real spring physics** — every letter has velocity, rotation and scale springs; double-tap / shuffle to toss them
- **Dela Gothic One** display type, EN / 繁中 toggle, white / silver / black themes (persisted)
- **Sliders** — force and size, live
- **PNG export** — one tap, download the current frame
- Single `index.html`, vanilla JS + Canvas 2D, zero dependencies, works offline (after fonts load)

## Run

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
